# Altitude — Frontend

React 19 + Vite + Tailwind CSS v4. See the [repo root README](../README.md) for the full project overview, architecture, and how to run it.

```bash
npm install
cp .env.example .env   # VITE_RAZORPAY_KEY_ID must match the backend's RAZORPAY_KEY_ID
npm run dev             # http://localhost:5173
npm run build            # production build
```
